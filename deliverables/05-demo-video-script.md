# 3 分钟 Demo 视频脚本（分镜）

> 主线一句话:**IM 范式 → 单聊流式 → 群聊 Orchestrator 自动分派 → 过程实时可见 → 共享工作区**。
> 录前按 `01-demo-runbook.md` §4 配好 cc 凭证,准备含 cc+ds 的群 `123131`。

| 时间 | 画面 | 旁白要点 |
|---|---|---|
| 0:00–0:15 | 登录后进入 AgentHub,展示左侧会话列表 + Agent 联系人(头像/能力标签) | "AgentHub 把和 AI 协作做成 IM:每个 Agent 是一个聊天对象,可单聊可群聊。" |
| 0:15–0:45 | **单聊 cc**:发"用 Rust 写快排+测试",回复**逐字流式**渲染,代码块高亮,展开"查看思考过程" | "单聊里,Agent 的回复是实时逐字生成的,代码内联高亮、可一键复制。" |
| 0:45–1:45 | **群聊编排**:群 `123131` 发"@主Agent 做个待办工具:ds 写前端,cc 写后端 Rust";依次出现 任务规划 → 每个子任务 ▶️ 开始执行 → **运行中实时过程气泡** → cc/ds 各自产出 → ✅ 协作完成 | "群聊里只要描述目标,主 Agent(Orchestrator)自动拆解任务、并行分派给合适的 Agent;**运行过程实时可见**——这是我们的重点优化。" |
| 1:45–2:05 | **pin 长期上下文**:把"所有代码必须用 Rust"置顶,再发一轮,Agent 持续遵守 | "关键约定可以置顶为长期上下文,多轮迭代不跑偏。" |
| 2:05–2:35 | **共享工作区**:右上角「文件」浏览 cc/ds 在同一目录写的产物;「终端」跑 `ls`/`cat` | "同一个群里的 Agent 共享一个工作目录、互相读写产物,还能在浏览器里直接看文件、开终端。" |
| 2:35–3:00 | 切到 git log(R1–R9)+ 一张架构图;一句话收尾 | "统一适配器层接入 Claude Code / Codex / 自建 Agent;整个项目用 Claude Code 结对开发,规格先行、advisor 复核、verify 闭环。" |

## 录制提示
- 屏幕分辨率/字号调大,保证代码可读。
- 群聊那段是核心,留足时间让"实时气泡 → 各 Agent 产出 → 聚合"完整出现。
- 如启用了 codex,可在群里多 @ 一个 cx 任务,口头点出"接入了 2 个主流平台"。
- 全程一镜到底优先;卡顿处可剪。
