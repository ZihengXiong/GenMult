# AgentHub 产品设计文档

> 对照课题《AgentHub-多 Agent 协作平台设计》的核心功能,逐条说明产品形态与实现状态。

## 1. 产品定位

AgentHub 把"与 AI Agent 协作"做成**IM 聊天范式**:用户像用飞书/微信一样,新建对话、发消息、@成员,与不同 AI Agent(Claude Code、Codex、Memoh 自建)单聊或群聊;群聊由主 Agent(Orchestrator)自动协调分工。统一适配器层屏蔽各 Agent 平台 API 差异,产物在聊天流中内联预览。

## 2. 核心信息架构

```
左侧:会话列表(新建 / 置顶 / 搜索 / 按活跃排序)
中部:聊天主区(消息流 + 富媒体卡片 + 输入框 + @ 与发起任务)
右侧:房间成员 / Agent 接入面板 / 工作区入口(文件·终端)
```

## 4. 体验亮点(对应"创新与产品感")

1. **编排全程实时可见(R5 + R9)**:单聊逐字流式;群聊运行中把 Orchestrator 通常丢弃的"思考/工具调用"过程,作为临时气泡实时呈现,消灭了"静默几十秒→末尾爆发"的黑盒感。
2. **长期上下文 pin(R3)**:用户置顶关键约定(如"必须用 Rust"),作为长期上下文持续注入,多轮迭代不跑偏。
3. **群内共享工作区(R4.1 + R8)**:同房间 Agent 共享一个工作目录、互相读写产物,并能在浏览器里直接浏览文件 / 开终端,把"多 Agent 协作"做实。
4. **凭证一处配置、单聊编排同源(R4/R7)**:在"通用设置"配一次 DeepSeek 兼容 Provider,单聊与群聊编排共用,且自动带上正确模型,避免空产出。
